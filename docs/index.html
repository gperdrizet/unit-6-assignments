Image Generation Benchmark

This benchmark compares generation latency, peak GPU VRAM, and peak system RAM across nine text-to-image diffusion models, four execution modes, and two GPU tiers. Each model is run three times per (model, mode) combination after one untimed warmup run.

Prompt: "a turtle and a bird together in a forest"

Output resolution: 512 × 512  |  Replicates: 3 timed runs per combination
